# Features

> Short films on what Blowhorn can do, from actions beyond the API to a remote team working as one army.
- [Remote team, one army](https://blowhorn.ai/resources/videos/features/remote-team/) - Every teammate runs Blowhorn on their own computer, signed in as themselves. You see the whole fleet and every result in one place. (0:24)
- [Beyond the API](https://blowhorn.ai/resources/videos/features/beyond-the-api/) - Platform APIs keep some actions for approved partners. Blowhorn works the way you do, so it isn't limited to what those APIs expose. (0:24)
